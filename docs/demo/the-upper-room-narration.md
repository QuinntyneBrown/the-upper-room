## Sign in

The Upper Room is a multi-city platform for managing contacts, partners, events and boards. Sign-in uses a secure PKCE flow. First, a wrong password is rejected with a clear message. Then the correct credentials take the administrator to the dashboard, where live counts and the navigation drawer are ready.

## Contacts

Now to the people. Choosing Contacts from the drawer lists every contact in the city, and the search box filters them as you type. Adding a new contact takes a first name, a last name and an optional title. After saving, the contact detail page opens with the new record.

## Events

Finally, events. From the drawer, the Events page shows what is coming up. Creating an event needs a title and a start and end time. Once saved, the event appears in the list, ready for the whole team.
