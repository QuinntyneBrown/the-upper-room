## Principles

- **Material underneath, our API on top.** Each component is a thin, standalone wrapper over an Angular Material
  primitive with a small, typed API — pages never import `@angular/material` directly.
- **BEM classes are a contract.** Components render stable BEM classes (`.tar-button--filled`) and `data-testid`s; the
  Playwright page objects locate by them.
- **Tokens by role.** Styles read `--md-sys-*` roles, never hex values, so light and dark schemes come for free.
- **Dialogs, not inline forms.** Button-triggered editing opens a CDK Dialog or navigates to a screen.
- **Accessible state.** Selection, expansion and validity are exposed through ARIA, not classes alone.
