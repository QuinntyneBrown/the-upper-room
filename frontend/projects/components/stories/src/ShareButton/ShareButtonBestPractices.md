## Best practices

### Layout

- Place it at the trailing end of a page or card header, next to other header actions.
- One share button per page; it always shares the page URL.

### Content

- Only use it on pages whose URL fully identifies what is shown (an event, a partner, a board), so the recipient sees the same thing.
- Don't add a visible "Share" label beside it; the icon is the established pattern.

### Accessibility

- The button is labelled "Share" for screen readers and is reachable with the keyboard.
- The clipboard fallback confirms with a snackbar, which is announced politely.
