# Motion

Short durations (`short1`–`short4`) for hover, press and selection feedback; `medium` for state changes such as a drawer
or dialog opening; `long` only for large, full-screen transitions. Under `prefers-reduced-motion: reduce` the global
stylesheet collapses every animation and transition.
