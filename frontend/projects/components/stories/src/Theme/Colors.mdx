# Colors

Material 3 colour roles generated from the seed `#6750A4`. Pair every container with its `on-` role — `primary-container`
with `on-primary-container`, `error-container` with `on-error-container` — so text always passes AA. Switch the toolbar
to **Dark** to see the dark scheme's values.
