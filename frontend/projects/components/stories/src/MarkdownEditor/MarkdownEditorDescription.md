A lightweight Markdown editor for idea descriptions and other long-form text. `tar-markdown-editor` is built from plain elements (no Material primitive) and is controlled: bind `value` and update it from `valueChange`, which fires with the full text on every keystroke and toolbar action.

The root `.md-editor` (`data-testid="markdown-editor"`) has Write / Preview tabs (`.md-tab`, `.md-tab--active`; `markdown-tab-write`, `markdown-tab-preview`). Write shows `.md-editor__toolbar` with `.md-toolbar-btn` buttons for bold, italic, heading, link, list and code (`markdown-toolbar-bold` … `markdown-toolbar-code`) plus an image picker (`markdown-toolbar-image`, hidden input `markdown-image-input`); the `.md-editor__textarea` (`markdown-editor-textarea`); and a `.md-char-count` (`markdown-editor-char-count`) that adds `.error` at `maxLength`. Preview renders `.md-editor__preview` (`markdown-preview-pane`).

Other inputs: `maxLength` (default 10000), `uploadUrl` (default `/api/v1/uploads`) and `maxUploadBytes` (default 10 MB). Picking an image posts it to `uploadUrl` and inserts `![name](url)`; files over the limit are rejected with an error snackbar. These stories stub the upload.
