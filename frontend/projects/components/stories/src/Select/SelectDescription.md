A single-choice dropdown. `tar-select` wraps an Angular Material `mat-form-field` (always `outline`) around a `mat-select`, rendering one `mat-option` per entry in `options` (`TarSelectOption`: `value`, `label`, optional `disabled`). It is controlled, not a `ControlValueAccessor`: pass `value` and listen to `valueChange`, emitted from `selectionChange` with the chosen option's value.

The form field carries `.tar-select` (plus `.tar-select--full-width`, on by default); the `mat-select` is `.tar-select__control` with `data-testid` from `testId` and `aria-label` falling back to `label`; each option is `.tar-select__option`. `hint` renders `.tar-select__hint`. `error` renders a `mat-error` (`.tar-select__error`, `data-testid` from `errorTestId`), which Material only displays when the control is in an error state — without a bound form control it is not shown.
